# 🛒 Магазин (Console App)


## 📌 Описание

Консольное приложение на Python — мини-магазин с корзиной товаров.
Пользователь может просматривать каталог товаров, добавлять их в корзину, указывать количество (в килограммах) и получать итоговый чек с датой и временем покупки.

---

## 🚀 Возможности

* 📦 Просмотр полного списка товаров с ценами
* ➕ Добавление товаров в корзину
* ⚖️ Ввод количества в килограммах
* 🧾 Просмотр содержимого корзины
* 💰 Автоматический подсчёт итоговой суммы
* 🕒 Отображение даты и времени покупки
* ❌ Валидация входных данных и обработка ошибок
* 🔁 Удобное меню для быстрой навигации

## 🎮 Использование

1. **Главное меню:**
   - Нажмите `1` для добавления товара в корзину
   - Нажмите `2` для просмотра корзины
   - Нажмите `0` для выхода

2. **Добавление товара:**
   - Выберите товар по названию (например: `apple`, `sugar`)
   - Введите количество в килограммах
   - Товар добавится в корзину

3. **Просмотр корзины:**
   - Увидите список всех товаров в корзине
   - Каждая строка: номер, название, количество, сумма
   - Итоговая сумма в конце

4. **Выход:**
   - Программа выведет финальный чек и завершится

## ⚠️ Обработка ошибок

Приложение корректно обрабатывает:
- ❌ Неверное название товара
- ❌ Отрицательное или нулевое количество
- ❌ Нечисловой ввод количества
- ❌ Неверный выбор в меню
